## Quick Start

1. **Watch the 60-Second Tutorial**  
   [Build an AI Agent in Under 60 Seconds on YouTube](https://www.youtube.com/watch?v=btOBqAJWFT8)

2. **Sign Up for Lyzr Studio**  
   - Go to [studio.lyzr.ai](https://studio.lyzr.ai/) and create an account via Google, GitHub, or email.  
   - Verify your email to unlock access to the visual builder and API keys.

3. **Create Your First Agent**  
   - In the Studio sidebar, click **New Agent**.  
   - Select a template or start from scratch, then configure the agent’s name, description, and default LLM.

4. **Configure Core Components**  
   - **Knowledge Sources**: Attach PDFs, web URLs, databases, or spreadsheets.  
   - **Tools**: Add built-in connectors (e.g. Slack, CRM) or custom REST integrations.
   - **Memory Modules**: Enable short-term or long-term memory as needed for context retention.

5. **Test & Refine**  
   - Use the built-in chat simulator to send sample queries.  
   - Fine-tune prompts, RAG parameters, and tool settings until responses meet your requirements.

6. **Deploy & Monitor**  
   - Publish your agent to the Lyzr cloud or invoke it via REST API in your application.  
   - Track usage, view audit logs, and adjust access controls in the AI Management System (AIMS).

You’re now ready to build, launch, and scale secure, responsible AI agents in under 60 seconds!
