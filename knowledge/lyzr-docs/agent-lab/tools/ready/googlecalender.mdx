The **Google Calendar** integration allows Lyzr agents to become personal scheduling assistants. From creating events to checking availability and sending reminders, your AI agents can fully manage time-based workflows.

---

## ✨ Key Features

- Create and update calendar events.
- Check time availability across calendars.
- Send automated reminders or follow-ups.
- Extract meeting context for pre/post notes.

---

## 💼 Example Use Cases

### 1. Smart Scheduling Agent
Book meetings without conflicts by reading calendar availability and coordinating with invitees.

> **Prompt**: “Find the next available 30-min slot with Alice and Bob this week.”

### 2. Post-Meeting Follow-Up
Create a task and send a summary email using event data after a meeting ends.

> **Workflow**: Calendar → Event Ends → Summary → Gmail & ClickUp

### 3. Daily Calendar Digest
Generate a daily brief of all events and send to Slack or Email at 8 AM.

> **Prompt**: “Summarize my day’s schedule and deliver it every morning.”

---

## 🔐 Permissions & Setup

- Requires Google OAuth
- Scopes include calendar.readonly and calendar.events
- Supports recurring events, invites, time zone handling

---

## 🛠 How to Set Up

1. Go to **Tools > Add Google Calendar**.
2. Authenticate your Google account.
3. Prompt test: 
   > “Create a meeting titled ‘Design Sync’ for tomorrow at 11 AM with Alex.”

---

Google Calendar becomes your agent’s scheduling backbone—enabling intelligent and conflict-free planning.
