Lyzr’s integration with **Twitter (X)** enables agents to engage in social listening, automate content publishing, track trends, and manage DMs—all via a natural language interface.

---

## ✨ Key Features

- Post tweets and replies.
- Retrieve tweet threads and engagement stats.
- Monitor hashtags, mentions, and keywords.
- Auto-respond to DMs or mentions using templates or AI.

---

## 💼 Example Use Cases

### 1. Auto-Tweet Agent
Automatically generate and post tweets based on blog updates or product announcements.

> **Prompt**: “Tweet: Just launched our new AI-powered search—check it out! 🔍 #AI #Productivity”

### 2. Hashtag Tracker Bot
Track industry keywords and summarize what’s trending every day or week.

> **Workflow**: Twitter API → Hashtag analysis → Summary → Notion or Slack

### 3. DM Support Agent
Use an AI agent to respond to common questions sent via Twitter DM and escalate when needed.

---

## 🔐 API Requirements

- Twitter Developer Access
- v2 API tokens (read/write permissions)
- Rate limit-aware handling of API calls

---

## 🛠 How to Set Up

1. Go to **Tools > Add Twitter Integration**.
2. Provide your Twitter Bearer Token or use OAuth.
3. Test with:
   > “Tweet a message celebrating our 1000th customer milestone!”
