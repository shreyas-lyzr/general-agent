Integrate **Calendly** with Lyzr to allow AI agents to schedule meetings, check availability, and automate appointment workflows with clients, prospects, or team members — all without human effort.

---

## ✨ Key Features

- Create new meetings or share booking links.
- Retrieve existing meeting schedules.
- Sync invitee details into other tools (e.g., CRM or ClickUp).
- Send reminders or follow-ups after meetings.

---

## 💼 Example Use Cases

### 1. AI Scheduler for Demos
Embed a Calendly link into your sales agent so it can directly schedule demos with qualified leads.

> **Prompt**: “Send my Calendly link to John and ask him to pick a slot this week.”

### 2. Post-Meeting Workflow
Trigger document creation or task assignment after a Calendly event is completed.

> **Workflow**: Calendly → Zapier/Integromat → Google Docs & ClickUp

### 3. Dynamic Scheduling Bot
Build a bot that shares your next available slot based on Calendly rules and Google Calendar sync.

---

## 🔗 Calendly Sync Features

- Works with Google Calendar or Outlook
- Time zone aware scheduling
- Buffer and cancellation policies honored

---

## 🛠 How to Set Up

1. Go to **Tools > Add Calendly Integration**.
2. Paste your Calendly API Key or connect via OAuth.
3. Share test prompt:
   > “Schedule a 30-minute intro call with my Calendly for next week.”
