Lyzr integrates with **Gmail** to let your AI agents communicate via email — autonomously and intelligently. This integration allows agents to compose, send, read, and manage emails as part of broader workflows.

---

## ✨ Key Features

- Compose and send emails using prompts or workflows.
- Read and summarize incoming emails.
- Search through your inbox for specific content.
- Attach files and format messages intelligently.

---

## 💼 Example Use Cases

### 1. Automated Email Follow-ups
Your sales AI agent can send personalized follow-up emails after customer demos or meetings.

> **Prompt**: “Send a thank-you email to all leads who attended today's webinar.”

### 2. Daily Digest Agent
Build an AI agent that summarizes unread emails every morning and sends a Slack notification.

> **Prompt**: “Summarize unread Gmail messages from the past 24 hours.”

### 3. Email-Based Ticketing
Automatically convert incoming support emails into tickets in ClickUp or Notion.

> **Workflow**: Gmail → NLP classification → ClickUp task creation

---

## 🔐 Security & Permissions

Lyzr uses secure OAuth scopes to request only the necessary access, such as:

- `gmail.readonly`
- `gmail.send`
- `gmail.compose`

---

## 🛠 How to Set Up

1. Go to **Tools > Add Gmail Integration**.
2. Authenticate your Gmail account securely via Google OAuth.
3. Test the connection using a test prompt like:
   > “Send an email to my secondary account with subject: Hello from Lyzr!”
