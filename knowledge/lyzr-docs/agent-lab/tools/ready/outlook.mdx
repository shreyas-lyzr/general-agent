Lyzr supports full integration with **Microsoft Outlook**, enabling agents to manage communication and calendar workflows inside enterprise environments using Microsoft 365.

---

## ✨ Key Features

- Send and receive emails through Outlook.
- Access and filter inbox content.
- Create calendar events and meeting invites.
- Extract actionable content from email threads.

---

## 💼 Example Use Cases

### 1. Executive Assistant Agent
Let your AI agent manage your inbox and calendar, summarize emails, and propose available meeting slots based on your Outlook calendar.

> **Prompt**: “Summarize emails from last 3 days and reschedule meeting with Raj.”

### 2. Enterprise Email Summaries
Create a Slack digest of your unread Outlook emails every morning for quick review.

> **Workflow**: Outlook → LLM summary → Slack message

### 3. Outlook + Teams + ClickUp Workflow
Trigger workflows based on email content—like creating a task when a client sends a deliverable approval.

---

## 🔐 Permissions & Setup

- Requires Azure Active Directory OAuth
- Supports Microsoft Graph APIs
- Scopes include: mail.read, mail.send, calendars.readwrite

---

## 🛠 How to Set Up

1. Navigate to **Tools > Add Outlook Integration**.
2. Authenticate using your Microsoft account.
3. Test with: 
   > “Send a follow-up email to John regarding the Q3 plan.”
