**Global Context** in Lyzr Studio allow you to create and manage reusable context documents that can be injected into agent system prompts. This ensures consistency, reduces redundancy, and makes it easier to manage domain-specific knowledge across multiple agents.

---

## 🔹 What is Global Context?

A **Global Context** is a reusable block of information (such as company details, product data, or policies) that can be attached to different agents. Instead of rewriting the same instructions or knowledge for every agent, you can centralize it once and reuse it anywhere.

For example:

- **Company Information** – General details about your organization.
- **Product Catalog** – List of products, features, or pricing details.
- **Support Guidelines** – Standard protocols for handling customer queries.

---

## 🔹 Step 1: Accessing Global Context

Navigate to the **Global Context** section in Lyzr Studio.\
Here you can view, create, and manage all context documents.

![](../../../assets/images/studio/gcon1.png)

If no contexts are created yet, the panel will display:\
`0 contexts available`

---

## 🔹 Step 2: Creating a New Context

To create a new context, click on **New Context**.\
You’ll be prompted to provide two fields:

1. **Name** – A short, descriptive identifier for your context.
   - Example: `company_info`, `product_catalog`, `faq_reference`
2. **Value** – The actual content of the context. This is the reusable instructions you want to provide to the agent.
   - Example:

     ```
     Our company, Lyzr AI, was founded in 2021 with a mission to make AI-powered automation accessible to all businesses.
     ```

![](../../../assets/images/studio/gcon2.png)

---

## 🔹 Step 3: Using it as part of an agent

- **Open** any existing agent or create a new agent
- **Enable Context** from the Agent features section
- **Select a Context** – Choose a specific context from list of all contexts created

These steps enabled to add context as part of agent instructions. You can reuse across Agents by applying the same context to multiple agents without duplicating effort.

---

## ✅ Benefits of Global Context

- **Reusability** – Create once, use everywhere.
- **Consistency** – Ensure all agents share the same baseline knowledge.
- **Scalability** – Easily manage and update context for multiple agents.
- **Efficiency** – Save time by avoiding repeated manual input.

---

## 🚀 Summary

The **Global Context** feature in Lyzr Studio streamlines knowledge management for your agents. By centralizing reusable content, you can maintain accuracy, reduce duplication, and ensure that your agents operate with the most up-to-date information.

Whether it’s **company details, product catalogs, or support protocols**, Global Context make it easy to scale your AI solutions while keeping them consistent and reliable.
